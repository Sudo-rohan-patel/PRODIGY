# PRODIGY
Cyber Security Internship Program at Prodigy InfoTech

Key Internship Tasks:
Task 1: Implement Caesar Cipher
Develop a Python program for encrypting and decrypting messages using the Caesar Cipher algorithm. This task will enhance your understanding of cryptographic techniques and text-based encryption methods.

Task 2: Pixel Manipulation for Image Encryption
Build a simple image encryption tool that manipulates pixels to encrypt and decrypt images. This task will give you insights into image processing and basic encryption techniques for visual data.

Task 3: Password Complexity Checker
Create a tool to assess password strength based on criteria such as length, character types, and complexity. This task will help you understand password security and best practices for safeguarding user accounts.

Task 4: Simple Keylogger
Design a basic keylogger to log keystrokes. While this tool provides an understanding of logging and monitoring, it’s essential to consider ethical implications and obtain proper permissions before usage.

Task 5: Network Packet Analyzer
Develop a packet sniffer to capture and analyze network traffic, focusing on details like source/destination IPs, protocols, and payloads. This task will familiarize you with network security analysis and packet inspection.
